# 📊 Interactive Sales Dashboard | Power BI

An interactive **Sales Dashboard** developed in **Power BI** to provide comprehensive insights into sales performance across products, sales channels, and states. The dashboard features **Light and Dark themes**, interactive visualizations, KPI cards, and cross-filtering to help users explore data and make informed business decisions.

---

## 🚀 Features

- 📈 KPI Cards displaying **Total Sales** and **Total Orders**
- 📦 Product Quantity analysis using a **Treemap**
- 🛒 Sales distribution by **Sales Channel**
- 🗺️ Interactive **State-wise Sales Map**
- 📊 Product-wise Sales comparison
- 📉 Sales Trend Analysis
- 🎨 **Light & Dark Mode** with seamless theme switching
- 🔄 Interactive filtering and cross-highlighting across visuals
- 📱 Clean and modern dashboard layout

---
